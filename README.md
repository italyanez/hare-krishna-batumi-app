# Харе Кришна · Батуми — Telegram Mini App

Статическое приложение без сборки: HTML, CSS и ES-модули. Публикуется папка `dist/`
(см. `.openai/hosting.json`).

```
dist/
  index.html        оболочка, подключение Telegram SDK
  content.json      ВСЁ содержимое: расписание, контакты, реквизиты, служения, записи
  css/app.css       единая дизайн-система (токены → компоненты → экраны)
  js/app.js         запуск, маршрутизация, шторки, копирование
  js/views.js       разметка экранов (данные → HTML)
  js/schedule.js    время Батуми, регулярные программы, статусы
  js/telegram.js    обёртка над Telegram Web App SDK
  js/icons.js       набор иконок
```

## Как обновить расписание

Все посетители видят один и тот же `content.json`. Чтобы изменить расписание,
отредактируйте файл и опубликуйте `dist/` заново.

**Регулярные программы** (`regular`) — повторяются каждую неделю (`weekday`: 0 — воскресенье).
Они показываются со статусом «По расписанию» или «Время уточняется».

**Конкретные события** (`events`) — то, что объявлено в канале. Поля:

| поле | значение |
|---|---|
| `id` | уникальный, например `2026-11-15-sunday` |
| `date`, `start`, `end` | `2026-11-15`, `14:00`, `18:00` (время Батуми; `end` можно не указывать) |
| `series` | id регулярной программы, которую событие заменяет в этот день (`sunday`, `tuesday`, `thursday`) |
| `status` | `confirmed` · `tentative` · `moved` · `cancelled` (статус «Завершено» ставится сам) |
| `place` | ключ из `places` (`temple`, `hilton`, `maharaj`) — добавьте новое место туда же |
| `note` | причина отмены/переноса или пояснение |
| `movedTo` | при переносе — `id` нового события |
| `guest`, `program`, `sources` | гость, порядок программы, ссылки на посты канала |

Пример: харинаму отменили из-за дождя — у того же события меняется `status` на
`cancelled`, в `note` пишется причина, в `sources` добавляется ссылка на пост об отмене.
Получается одна актуальная карточка, а не два несвязанных сообщения.

После правки обновите `updatedAt` — дата показывается на главной.
При изменении CSS/JS увеличьте `?v=` в `index.html` и в `import` внутри `js/`, чтобы
Telegram не показывал старую версию из кэша.

## Ссылки на разделы

`#home`, `#schedule`, `#donate`, `#donate/sber`, `#donate/tbc`, `#donate/usdt`,
`#service`, `#temple`, `#temple/contacts`, `#temple/first-visit`, `#records`.

Когда будет настроена Main Mini App, ссылки вида
`https://t.me/harekrishnabatumi_bot?startapp=donate_usdt` откроют сразу нужный раздел
(`раздел_аргумент` → `#раздел/аргумент`). Пока не проверено в Telegram.

## Локальный просмотр

```bash
python3 -m http.server 8765 --directory dist
```
